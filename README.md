# 🌍 Global Analysis of the COVID-19 Pandemic

## 📖 Background

Since late 2019, the COVID-19 pandemic has had a profound impact on global health, the economy, and society. The virus's rapid spread, high death toll, and the global vaccination campaign have prompted various policy responses. Therefore, analyzing case numbers, deaths, and vaccination data is crucial to understanding the dynamics of the pandemic and supporting more effective decision-making for response and recovery.

## 🎯 Project Objectives

* Identify the most affected countries based on the number of COVID-19 cases.
* Assess the fatal impact of the pandemic in countries with the highest death tolls.
* Analyze daily trends to evaluate virus spread and the effectiveness of interventions.
* Compare case numbers across continents to understand global transmission patterns.
* Evaluate vaccination progress and its impact on pandemic control.

## 📊 Dataset

The dataset used in this project is sourced from [Our World in Data](https://ourworldindata.org/explorers/covid), a globally recognized repository offering detailed COVID-19 statistics. The dataset consists of 67 columns and 397,544 rows.

## 🧪 Analysis Steps

* Data Cleaning
* Handling Missing Values
* Data Transformation
* Handling Inconsistent Values
* Data Visualization
